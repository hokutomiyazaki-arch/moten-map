# 盲点マップ ─ 盲点の大きさと形を左右で比べる（FNT Lite PWA）

BDC「皮質の左右差のアセスメント（盲点）」（https://bodydiscovery.jp/photo/blind-spot/ ）を、紙とペンの代わりにスマホ1台で行うアプリ。

## 測り方（アプリの流れ）
1. 目と壁の距離を約30cmにし、壁の目の高さに目印を1つ作る。右目を測るなら左目を手で覆い、壁の目印だけを見続ける。
2. スマホを縦向き・画面をこちらに向け、目印のすぐ右横、目の高さで壁に当てる。
3. スマホを壁に沿ってゆっくり右へずらす。点が消えたら止め、壁に当てたまま固定する。この開始点が1点目（鼻側の端）。
4. 下の大ボタンを押し続ける。点がゆっくり外（耳側）へ動き、見えた瞬間に離す＝2点目（外の端）。
5. 点が開始点と外の端のちょうど中間に戻る。そこから上→下→外の斜め上→外の斜め下→鼻側の斜め上→鼻側の斜め下を同じように取る。開始点を含め合計8点。
6. 左目も同じ距離で測る。右目を覆い、目印の左側でスマホを左へずらす。8点を角度順に結んだ左右の形・大きさを結果で比べる。

ホーム・準備画面・メニューの「デモを見る」から、約1分の自動説明アニメを見られる。初回の「右目から測る」は先にデモを表示し、終了・スキップで準備へ進む。前／次／一時停止・再生／閉じるで操作でき、字幕の読み上げは音声ガイド設定に従う。

## 決めたこと
- 鼻側の点は開始点を使い測り直さない。壁に当てるので左右の距離がそろう。目と壁の距離を左右同じに（約30cm）して比べる。
- 開始点は画面中央より14%鼻側。外・上・下・斜め4つの7方向を動かし、開始点と合わせて8点を保存する。最初まで戻すと鼻側・外の2点を取り消す。
- 端で止まった点は赤で表示。目と壁の距離を少し縮めて（25cmくらい）、両目とも同じ距離で測り直すよう促す。
- 外側を取った後の中点計算・EDGE・速さ設定は維持する。
- 外観はFNTアドバンス共通の黒×金。Noto Sans JP／Shippori Mincho／Cormorant Garamondを使用。測定画面は温かいアイボリーに黒い点、下のボタンは黒×金。
- 結果は暗い背景に右目＝琥珀、左目＝青、前回＝グレーの点線。
- デモはindex.html内のSVGを毎フレーム描画し、自動で場面を進める。外部ライブラリ・動画ファイル・点滅は使わない。見た記録をlocalStorageに保存する。
- 測定中は記録した点や線を画面に出さない。線は盲点を横切ると脳が埋め合わせて見えてしまい、判定を邪魔するため。
- 上下の割合は「盲点自身の上端と下端の真ん中」で切る。スマホを持つ高さのずれに左右されないように。
- 区切り（面積の差10%未満＝ほぼ同じ／上下55:45超＝大きい）は表示上の目安で正常値ではない（基準は介入の反応で決める方針）。
- 読み方の文はBDCのページの記述だけから作る（右目＝左の皮質、下が大きい＝頭頂葉、上が大きい＝側頭葉、打ち手）。
- 記録は端末の localStorage に最新30件。前回の形を点線で重ね、面積の増減を出す（ドリル前後の比較用）。

## ファイル
index.html（本体）／manifest.json／sw.js（Network First、CACHE_NAME を上げて更新）

## 動かす
`python3 -m http.server 8080` → http://localhost:8080/
